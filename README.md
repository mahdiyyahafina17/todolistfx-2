Project Description

The To-Do List Application is a JavaFX-based desktop application developed using Object-Oriented Programming (OOP) concepts. The system allows users to register, log in, and manage their personal and academic tasks efficiently. Task information is stored in text files to ensure data persistence.

Features

User Management

* User Registration

  * New users can create an account.
* User Login

  * Registered users can log in securely.

Dashboard

* Provides navigation to all application functions.
* Allows users to access Personal Tasks and Academic Tasks modules.

Personal Task Management

* Add personal tasks.
* Edit personal tasks.
* Delete personal tasks.

Academic Task Management

* Add academic tasks.
* Edit academic tasks.
* Delete academic tasks.

File Handling

* User information is stored in `users.txt`.
* Task information is stored in `tasks.txt`.
* Data is retained even after the application is closed.

JavaFX GUI

* Interactive graphical user interface built using JavaFX.
* User-friendly navigation and task management.

How to Run

1. Open the project in NetBeans.
2. Build the project using Maven.
3. Run the `TodolistfX` class.
4. Register a new account or log in using an existing account.
5. Start managing personal and academic tasks.
